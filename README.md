## 🚀 Projects & Products

### 1. Red Pen — AI-Powered Answer Annotation Tool

A teacher-style annotation tool designed to make answer-copy evaluation and feedback easier.

- Independently built and deployed the application using AI-assisted development.
- Supports highlights, contextual comments, ticks, crosses, underlines, strike-throughs, stamps, and scoring.
- Enables export of annotated PDFs, JSON, and HTML.
- Adopted by **70+ SMEs** for evaluation workflows.

### 2. PW Creative Hub — Digital Asset Management Platform

A centralised platform built to simplify digital content organisation and discovery.

- Built using React.js, TypeScript, Node.js, Express.js, and MongoDB.
- Integrated Google Drive and implemented taxonomy-based filtering and structured search.
- Reduced asset discovery time from over a day to approximately **5 seconds**.

### 3. AI Tutor — Interactive Learning Prototype

An AI-powered learning experience designed to make doubt resolution more interactive.

- Developed a React-based interactive whiteboard with hand-drawn animations.
- Integrated Gemini API for real-time doubt resolution.
- Explored vernacular voice experiences using Sarvam AI and ElevenLabs.
- Experimented with 3D and simulation-based learning experiences.

### 4. AI Grader+ — AI-Powered Evaluation Platform

Working on an AI-powered platform that evaluates subjective and mixed-format student answer copies.

- Driving product initiatives across evaluation workflows, student results, and question-level feedback.
- Working on AI grading quality through Golden Datasets, model benchmarking, and evaluation frameworks.
- Led the development of an annotation-based result experience to make feedback more actionable for students.

### 5. Eval Builder — AI Evaluation Platform

Exploring a platform that helps developers build structured evaluation systems for AI applications.

- Focused on connecting code repositories and setting up evaluation workflows.
- Exploring ways to assess AI application quality through structured evaluations.
